# DZ Wholesale Scanner — نسخة أولية

## ماذا تتضمن؟
- صفحة عربية/فرنسية متجاوبة للهاتف.
- إضافة وتعديل وحذف المنتجات.
- حفظ قائمة المنتجات محلياً في المتصفح.
- استيراد وتصدير قائمة المنتجات بصيغة JSON.
- زر بحث يرسل قائمة المنتجات إلى Gemini مع Google Search grounding.
- النتائج تعرض السعر ونوعه والمورد والولاية والتاريخ والرابط عندما تتوفر هذه المعلومات.

## حدود مهمة
1. هذه نسخة أولية: النتائج ليست ضماناً لتوفر المنتج أو صحة سعر الجملة.
2. قد لا تكون إعلانات Facebook أو مجموعات WhatsApp العامة قابلة للفهرسة أو الوصول.
3. لا تعني عبارة «لم يُعثر على سعر موثوق» أن المنتج غير متوفر في السوق.
4. في النسخة الحالية تحفظ قائمة المنتجات في المتصفح/الهاتف نفسه. لا تمسح بيانات المتصفح قبل تصدير نسخة احتياطية.
5. واجهة البحث تحتاج مفتاح Gemini API محفوظاً كسِرّ في Cloudflare Worker. لا تضع المفتاح في index.html ولا تشاركه مع أحد.
6. الخدمة المجانية ليست بلا حدود؛ راجع حصص Gemini وCloudflare قبل الاستخدام المكثف.

## النشر (يحتاج حاسوباً مرة واحدة)
1. أنشئ حساباً في Cloudflare.
2. أنشئ مفتاح Gemini API من Google AI Studio.
3. نزّل Node.js على الحاسوب.
4. فك ضغط مجلد المشروع.
5. افتح الطرفية داخل مجلد المشروع ونفّذ:

   npm install -g wrangler
   wrangler login
   wrangler secret put GEMINI_API_KEY

   ألصق المفتاح عند الطلب (لن يظهر أثناء الكتابة).

6. انشر المشروع:

   wrangler deploy

7. سيظهر لك رابط من نوع `https://dz-wholesale-scanner.<اسمك>.workers.dev`.
8. افتح الرابط في Chrome على هاتفك، ثم من القائمة اختر «إضافة إلى الشاشة الرئيسية».

## استخدام الصفحة
- أضف اسم المنتج، ويمكنك إضافة العلامة التجارية والتهجئات البديلة.
- اختر نوع السعر: جملة أو تجزئة أو كلاهما.
- اضغط «تحديث جميع الأسعار الآن».
- افتح رابط المصدر للتحقق من العرض قبل الاعتماد عليه.
- صدّر قائمة المنتجات دورياً كنسخة احتياطية.

## ملاحظة تقنية
النظام يستخدم Google Search grounding عبر Gemini API. لا يوجد ضمان أن محرك البحث سيجد جميع الموردين أو الأسعار، ولا أن جميع النتائج منشورة حديثاً. إذا تغيّر اسم النموذج أو صيغة API، قد نحتاج إلى تحديث worker.js.
